## 契约变化（调用方须知）

1. **八个召回运行时动作 operation_id 必填**：start/refine/reject/
   accept/navigate/close/round2/words.recall + find_words。缺省 →
   SCHEMA_VIOLATION。service 层直调（op_ctx=None）不受影响。
2. words.recall / find_words 的 MCP annotations 现为
   readOnlyHint=false——客户端不应再对其做透明自动重试（幂等由
   operation_id 显式承担）。
3. 带 operation_id 的响应经 run_operation 包装：
   `{"data": <packet>, "idempotent_replay": ...}`（与既有 round2/
   words.recall 形态一致）。
4. browse（无检索词 latest-K）coverage 现为 `partial_topk_window`，
   不再给 round2 背书。
