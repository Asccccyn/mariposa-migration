## 契约变化（调用方须知）

1. `media.upload.finalize` 不再接受 `data_b64`（schema 结构性拒绝）——
   字节必须先经 `PUT /api/media/stage/{token}`（Bearer 鉴权 = token
   owner）落盘。
2. `memory.hold` 带 `plan` 分类时必须传 `plan_ids`（指向存在的 plan）。
3. Jev 缓存指纹不变（query_projection 未动）；anchors 只影响出站
   envelope 内容。
