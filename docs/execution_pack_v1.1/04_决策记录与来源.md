## 2. 对旧 v0.4 的覆盖

| 旧条款 | 本次结论 |
|---|---|
| memories 表内 status=candidate | 废止。草稿正文进独立 workspace；formal只存提交控制元数据及批准后的内容。 |
| 自动压缩或乔生forget立即tags_only | 废止本轮默认。先形成摘要提案并审批，再切摘要检索。 |
| 遗忘层默认降低或排除普通语义召回 | 替换。遗忘摘要直接参与关键词和语义召回；旧正文不参与。 |
| her_quotes 逐字且是raw子串 | 废止。允许复述，只有实质语义冲突才纠正。 |
| 模型现场source_excerpt视为已核验raw | 不采用。作为可用复述/临时来源保留，不计入真实原文30条。 |
| 行为日志actor只写jiaming | 废止。Q/J/Worker/System明确分开，作者/执行者/入口分别记录。 |
| 任意Chat工具活动与handoff时间计last_contact | 废止。真实对话证据与程序/UI活动分开。 |
| Home+Self+两封信+quote+多篇日记全文+全部旧目录自动注入 | 替换为新bootstrap规则；轻量共同Home/Time属于基础配置，其他按需。 |
| 所有Open Loops默认全部加载 | 替换为进行中/临近与仍未完逾期项，不取全量计划。 |
| 通用purge双方同意并物理删除Raw | 不直接采用。以本地现有删除语义为准，不能凭旧稿新增物理删除。 |
| Handoff 72小时后归档 | 作为可选便签过渡保留；不默认自动注入，过期不擅自变成物理删除。 |
| 同一来源不重复Hold | 保留防重复；多事件共跨度先审阅/拆范围，不擅自放开或误删。 |
| I需要dream见证才正式 | 不采用；自己写即正式，另一个日期回看一次。 |

## 3. 工程默认，不冒充用户逐项确认

30天遗忘初筛是用户举的例子；分类边界、摘要最终长度仍可继续调整。七天临近范围、30条按消息计、三天按自然日、16000 token软提示、20条扫描批次、拒绝冷却、自动任务初期开关，是本版工程默认。

项目路径、18780/5178端口、数据库/前端技术栈、proposal跨库提交协议是技术选择；需要现场验证兼容性。任何数值都应由版本化配置控制，不散落硬编码。

Home保留为共同轻量背景，不意味着恢复旧庞大开窗包。日记/Self/信件独立模块保留，并不是因为不自动塞全文就被删功能。

便签长期保存期限未最后确定。本版不自动销毁它；只有最新/未过期用于按需交接，不进普通召回。以后明确保留期限再实现回收任务。

未来情绪/欲望算法、音乐供应商、原生移动端不假装已冻结。不因为预留接口就说后端已拥有真实功能。
