## 交给 GLM 的阅读顺序

先读 `00_给GLM的开工指令.md` 和 `05_连续执行模式.md`，再读 `01_工程执行文档.md`；核对 `04_决策记录与来源.md` 的新旧规则覆盖；实现时对照 `02_验收用例.md` 与 `contracts/`；涉及数据时必须读 `03_迁移与切换手册.md`。

原稿仅在 `references/`，新决定优先，不能把原稿的逐字原话、候选混表、旧开窗包或通用物理purge重新搬回来。

## v1.1 改了什么

只改变执行方式：明确连续推进 Phase 0–8，自动测试、修复、提交和继续；汇报不等于等用户接力。Phase 9、真实快照及外部副作用仍单独授权。原 `01`–`04`、所有业务 contracts 与 v0.4 原稿逐字节保留，不变更产品范围、身份、审批或验收要求。

已经把 v1.0 发给 GLM 时，只追加 `05_连续执行模式.md` 即可，不需要让它重建已完成的工程；尚未开始时直接使用本包。执行包 v1.1 不是应用版本号，也不表示代码升级已执行。
