# 给 GLM：连续实现 mariposa（执行方式 v1.1）

你现在接手的是江乔生的新项目 **mariposa**。阅读本文件和 `05_连续执行模式.md` 后，依次读取 `01_工程执行文档.md`、`04_决策记录与来源.md`、`02_验收用例.md`、`03_迁移与切换手册.md` 和 `contracts/`。

**先读最新规格，再看 reference v0.4。不要把旧规则改回来。**

## 任务目标

独立新建 mariposa 的核心，选择性继承现有 Ombre 的适用代码与经核验的信件/删除行为，无损迁移现有正式数据。开发与旧生产隔离。建议目录 `D:\mariposa`，若已存在先盘点，不覆盖。

Claude Chat 与 CC 是同一个周家明的两个平等入口；GPT Chat 与后台模型是工具人。你作为实现者不自动拥有周家明的身份或审批权。

## 本轮不能做错的要求

1. 正式库和工作区分开。工具人的候选、遗忘摘要草稿只放工作区；未经审批不能污染正式记忆。
2. 工具人初筛并预处理遗忘，乔生或周家明任一方审批；审批针对具体版本/hash。未审批一直不生效。
3. 遗忘桶仍参加检索，但只有审批摘要参与关键词/语义检索；旧正文/旧向量/旧meaning/旧缓存不能参与或自动展开。
4. “她的话”允许周家明复述。以后导入原文，只纠正实质语义冲突，不能恢复逐字子串标准。
5. 日历按事件日期聚合记忆、计划等；不是复制另一套日历记忆。遗忘桶在日历中只显示摘要。
6. Chat 开窗读取30条真实主对话消息、三天桶和进行中/临近计划；CC读取三天桶和同样计划，原文按需。
7. 分清真正用户对话、用户浏览/审批、周家明动作、工具人动作、系统动作；不能把扫描时间当成见面时间。
8. letter/删除抄**本地当前实际行为**，不是凭上游最新代码或旧架构文档猜；不能新增无限制物理删除。
9. CC 第一版要求真实 Claude Code 的已核验订阅路径；不偷偷改成 API 模型，不用 `--bare` 换成 API 后说订阅已接通。
10. 情绪系统、一起听歌供应商、原生手机 App 按明确范围预留；不要把留接口伪装成功能已上线。

## 从哪里开始，并持续做到哪里

先执行 Phase 0 的只读盘点：两个旧 Ombre 目录、真实运行版本、未提交修改、配置/数据卷、旧信件和删除行为、可复用代码与测试、CC/MCP 平台前置条件。源中有真实敏感数据时仅列元数据，不把锁信或全部聊天原文打印给模型。

随后按 Phase 1 → Phase 2 实现第一条纵向闭环：身份/正式库/工作区 → 遗忘提案 → 审批 → 检索摘要切换 → 恢复。先做这条可测试的完整流程，不先画一堆静态页面。闭环通过后自动推进 Phase 3–8，完成原规格内的其他模块、全量测试、修复与发布候选；不得把 Phase 2 当成总任务终点。

你可以持续推进已经授权的隔离开发，无须每个小步骤都问“继续吗”。本地无法核验的部分标 blocked 并给出实际原因，继续独立模块；不能猜测后宣称通过。真实快照、外部副作用、凭据计费方式变更和生产切换不属于本开工指令的自动授权。

## 开发纪律

- 代码、schemas、迁移脚本、测试一起提交；每阶段单独可追踪 commit。
- 统一 Capability Registry：Web/MCP/CC 调同一业务逻辑；HTTP 与 MCP 不分别写一套记忆算法。
- 每个写动作实现幂等；修改实现版本冲突；每条审批都有真实认证后的主体记录。
- 依赖版本锁定；进程/端口/数据目录只属于 mariposa；不要停掉或修改别的项目。
- 不用 mock/provider stub/固定JSON 充当真实接通。`not_started`、`tested_mock`、`verified_live`、`blocked` 分别报告。
- 118 条验收用例是最低测试需求，目前未执行。将用例 ID 映射到实际测试文件、命令和结果，不能直接改清单为全绿。
- 不通过删除失败用例、放宽权限、把语义搜索关掉等方式“修好”验收。
- 文档提及的 scripts/commands 是你要实现的交付目标，不要假定已有可执行代码。

## 每个阶段汇报后自动继续

阶段与 commit；实际改动文件；schema 变化；运行的测试及结果；真实联调与模拟的区别；未完成/阻塞；确认未动哪些旧生产边界；下一阶段位置。同步写入 `docs/PROGRESS.md` 和 `docs/NEXT.md`，会话中断后从文件续接，并维护 `docs/BLOCKERS.md`。阶段短报不是停工等批准；依赖与验收满足后自动继续。缺外部条件只阻塞相关链路，继续独立工作。Phase 9 仍须单独批准，不能自动上线。

**先保护旧家，再搭新家。迁移时换程序，不重新改写你们的记忆。**
