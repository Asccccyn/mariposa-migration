# JEV 同轮浮现修复与验证（2026-10-21）

本批为源码修复，未启用或重启生产服务。estomago 基线 ee8e398；Mariposa 基线 545ae22。

## 最终行为

- 同一 N 消息的当前修订 prepare/validate/check 后用于回复 N；不延后到 N+1。
- E 总预算默认 15,000ms，从接受消息起算，超时只丢弃浮现。M prepare 10,000ms，delivery 4,000ms；逐候选/缓存/网络重试检查剩余时间，HTTP timeout 不超过剩余预算，迟到结果不写判断缓存。
- 准备阶段 same_occurrence 默认 0.75；交付阶段 same_occurrence 默认 0.80，relevant_now 默认 0.80；risk 仍为 0.02。事实冲突、证据不足、未知竞争候选继续阻断。分数不是概率，不代表正确率保证；环境显式覆盖仍优先。
- TypeSafe 问句引用的 request 字段现在实际出现在 state；同轮源快照仅有身份/hash时，只从 ID、修订、hash 全部相等的 target 补正文。prepare/delivery prompt 升到 v3，policy revision=3。
- 编辑并重发/路由编辑重发，在修订与 attempt 的同一事务内撤销旧任务、登记新修订任务，提交后唤醒。先仅保存再显式重试也补任务。普通仅保存不检索；同一回执重放不重复建任务，不重置已有修订的 deadline。
- provider 超时/连接中断明确 blocked，不冒充 empty；不自动重发结果不明的付费请求。

## 缓存与隔离

旧聊天轨迹、工具集和窗口未改写；同轮浮现仍只增尾部。JEV 合同指纹含新的交付阈值和 v3 提示词，旧缓存保留但不混用新规则。没有清缓存、没有强制换窗、没有使用真实 OR key。

## 真实 JEV 证据

全部为预先标注的合成输入、隔离数据库，只调用 TypeSafe JEV（resolved jev-1.13.0）；禁用 Dense 下载和真实聊天服务。
本轮开发验证共 190 次 HTTP 尝试，包括探索、独立样例、完整链及上游错误诊断；不等于 190 次成功或计费量，未取得完整账单费用。
旧 0.98 下第一组 9 个正例有 8 个返回准备分数，均不满足确认门，另 1 个上游失败。准备分数 0.75–0.95；正确事件确实会被阈值挡住。第二组 12 个样例用于复核，不把调参集当生产准确率。
5 候选准备真实耗时 2463ms，3 候选 1245ms；旧 2 秒总预算不足以覆盖该 5 候选样本，更不含检索和交付。
最终 32 组合成样例走真实 prepare→同 N validate→check：15 正例中 9 条交付且 check=true，6 条为上游失败；17 反例中 0 错误交付，14 条正常弃权，3 条上游失败。失败不算正确拒绝/通过。成功正例完整链约 0.84–1.15 秒。随后单独诊断 3 个失败样例，2 个正常交付，1 个 transport_http_interrupted；原始失败仍保留，不回填为通过。
有效响应已固化为 23 个离线回放用例；这是有限样本验证，不能宣称生产召回率100%，外部服务可用性仍有限制。
