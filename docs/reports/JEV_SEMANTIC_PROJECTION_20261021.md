# 自动浮现语义投影与两层详情（2026-10-21）

## 本批实现

JEV v4只发送一次target、必要的context、相对日期需要的time_basis，以及候选{id,date,title,text}。每个候选沿用既有一次请求；questions/noul与两阶段判定保留，问句键缩为c0_same_occurrence/c0_relevant_now。后端保留真实候选ID与版本映射；没有让JEV生成正文、摘要或替代真实候选选择。

context只在省略/指代信号需要时提供，最多6条，保留用户/助手来源标签但移除ID、修订和顺序。此为确定性保守规则，不宣称能完美理解所有省略表达。相对日期使用消息携带的固定occurred_at和Asia/Shanghai，不用每次调用的当前时间猜测。时间基准加入判断缓存身份。

最终新注入严格为 {"memories":[{"date":"2026-07-09","text":"完整原文"}]}。未知日期为null；不截断正文、不摘要、不附标题/分类/ref/说明句。多事件保留多个对象。旧冻结包和已发送轨迹不重渲染、不删改。

版本、修订、body_hash、domain_versions、授权与编辑失效检查仍在原后台管线。policy revision=4，prompt版本v4，使新投影与旧判断缓存隔离；不删除旧缓存。

## 同桶全量

新增已认证的 /api/v1/conversations/:room/turns/:turn/memories 列表与 /:memory_ref 详情入口。后台仅从该轮、该房间、该窗口实际已发送请求对应的投递记录解析引用。列表的ref是界面使用的私有定位句柄，不加入模型记忆正文。

前端“本轮回忆→查看全量→继续读取全量”调用同一个桶的memory.detail.read，保留现有分页、权限和快照有效性规则。展示日期标题、分类、心情、事件、我们的话、后来的回忆、留存、来源和正反向关系；部分不可用如实提示。没有任何recall回退、额外生成或摘要层。原有模型memory_read_full工具定义未改，兼容旧窗口已经拿到的旧引用。
